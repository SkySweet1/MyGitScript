# Лабораторная работа: Мини-система контроля версий
## Цель
Реализовать упрощённую систему контроля версий с возможностью сохранения состояния проекта.

---
## Описание

Необходимо написать программу `mygit.py`, которая позволяет сохранять версии текущего состояния файлов в директории проекта.
Программа должна работать из командной строки.

---

## Поддерживаемые команды

### 1. Инициализация репозитория

```
python mygit.py init
```
Создаёт служебную папку `.mygit`, в которой будет храниться история.

### 2. Коммит
```
python mygit.py commit "message"
```
Сохраняет текущее состояние файлов проекта.
При коммите:
обходить текущую директорию
игнорировать:
  папку `.mygit`
  файлы и папки из `.mygitignore`

### 3. Чекаут
```
python mygit.py checkout <id>
```
Принудительно заменяет файлы из директории на их версию под номером <id>

---

## Формат `.mygitignore`
Файл содержит список конкретных названий файлов, которые нужно игнорировать.

---

## Требования

использовать стандартные библиотеки Python
корректно обрабатывать вложенные папки
сохранять структуру директорий
